# Card Battler Reading Game

Playable browser demos of **Legendary Card Competition**, a card battler for struggling readers where you trace, name and sound out letters to play your cards.

- **Play:** [demos](demos/) (on GitHub Pages: https://otherwiselabspbc.github.io/card-battler-reading-game/demos/)
- **Concept:** [docs/concept.md](docs/concept.md)
- **Demo specs:** [docs/specs/](docs/specs/)
- **Building with Claude Code:** see [CLAUDE.md](CLAUDE.md)

Demos run in desktop Chrome. Allow the microphone for speech, or add `?speech=off` to play with taps.
